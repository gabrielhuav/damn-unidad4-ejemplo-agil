# Prueba de permiso de ubicación denegado

## Preparación

Usar una cuenta y reporte ficticios. Iniciar en la pantalla de nuevo reporte con un borrador de texto. Restablecer el permiso de ubicación en el dispositivo de prueba según las instrucciones del sistema.

## Pasos

1. Solicitar ubicación desde una acción visible del formulario.
2. Rechazar el permiso cuando el sistema lo ofrezca.
3. Comprobar que el texto del borrador sigue presente y que existe la referencia manual.
4. Escribir una referencia ficticia y continuar sin coordenadas.
5. Salir y regresar según el criterio de conservación acordado.

## Resultado esperado

La UI explica que no obtuvo ubicación. El rechazo no provoca un cierre ni pierde el borrador. La app no repite el diálogo indefinidamente. La referencia manual permite completar el flujo definido.

## Evidencia

Registrar plataforma, sistema, resultado y captura completa con el mensaje o control marcado en la presentación. Esta guía no afirma que la aplicación ya haya ejecutado la prueba.
