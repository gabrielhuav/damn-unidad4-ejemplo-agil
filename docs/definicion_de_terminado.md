# Definición de terminado

Una historia cumple los criterios particulares acordados y además:

- El código y configuración se integran mediante PR enlazado al issue.
- Las pruebas relevantes pasan y sus resultados se conservan.
- Otra persona revisó el cambio y se resolvieron sus observaciones.
- Se probaron permisos denegados, errores y cancelación que afecten al caso.
- La documentación permite reproducir el resultado.
- No hay claves privadas ni datos reales en archivos o evidencias.
- El incremento funciona en los destinos y dispositivos comprometidos.

Los criterios de aceptación describen cada historia. La definición de terminado establece la calidad común del incremento. En este ejemplo no hay una implementación móvil terminada.
